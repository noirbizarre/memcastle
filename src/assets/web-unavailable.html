The dashboard is enabled but its files are missing

This daemon was started with web.enable = true, but it found no web/dist/index.html in its runtime assets. The daemon itself is running normally, and the REST API and MCP are unaffected.

To fix it, do one of:

  • install a MemCastle package or release archive, which carries share/memcastle/web/;
  • in a checkout, run mise run web:build and start the daemon with --assets-dir "$PWD";
  • set web.enable = false (or unset MEMCASTLE_WEB_ENABLE) to stop serving /ui.
